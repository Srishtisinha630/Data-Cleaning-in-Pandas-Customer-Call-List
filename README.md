# Data Cleaning in Pandas - Customer Call List

This project demonstrates **data cleaning techniques using Pandas** on a customer call list dataset.  
The goal is to preprocess raw customer data by handling missing values, fixing inconsistent formats, and ensuring the dataset is analysis-ready.

---

## 📌 Features
- Handling **missing values** (NaN entries, empty strings).
- Standardizing **phone number formats**.
- Removing **duplicate records**.
- Correcting **inconsistent data entries**.
- Renaming and organizing columns for clarity.
- Converting data types where necessary.

---

## 🛠️ Technologies Used
- **Python 3**
- **Pandas**
- **Jupyter Notebook**
